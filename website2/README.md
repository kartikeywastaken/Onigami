# onigami website (shrine / garden)

A second showcase site for **onigami**, an agentic red-team crew for your terminal.
Shrine aesthetic (朱塗 vermilion + gold on lacquer), the Type Garden signature
(words grow into sakura as you type), Playfair Display + DM Mono + Shippori
Mincho. Built with Astro + GSAP + Lenis (no WebGL; the signature is a 2D canvas).

Adapted from the `cfafo/onigami` design reference: the design and garden are kept
intact; the content is re-anchored to the real onigami tool. All copy lives in
`src/data/site.ts`; the concept is in `DESIGN.md`.

## Develop

```
npm install
npm run dev        # http://localhost:4321
npm run build      # runs scripts/standalone.mjs, then astro build → dist/
npm run preview
```

## Placeholders to replace

Marked `placeholder: true` in `src/data/site.ts`: the production URL
(`onigami.dev`), the GitHub URL, and the install/build commands. Regenerate
`public/og.png` and the favicons for the brand, and the `site:` URL in
`astro.config.mjs` / `public/robots.txt`.

The `/type-garden.html` download (generated by `scripts/standalone.mjs`) is a
self-contained offline copy of the garden; it ships ttf fonts on purpose for
portability.
